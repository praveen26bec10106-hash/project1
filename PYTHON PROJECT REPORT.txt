➡️Project summary:- 

The High or Low Number Guessing Game is a text-based, interactive Python programme. The game challenges players to predict whether a randomly generated  number (between 1 and 200) will be higher or lower than the currently displayed number. If user guesses the number is either higher or lower correctly then he will get +10 points otherwise -5 points will be awarded to user. At last after 10 rounds players name and remark will be given according to points and his name will be saved in leaderboard. The project demonstrates core programming principles including loop control, conditional logic, error handling, function modularity, and basic data structure sorting for a leaderboard system. The project is made using the basic 5 modules taught to us and vityarthi course.

➡️ Game Rules & Mechanics:-
Starting Conditions: Every player starts with a base score of 50 points.
Rounds: A single game session lasts for a maximum of 10 rounds.
Scoring Matrix:
 Correct guess: +10 points 
 Incorrect guess: -5 points 
 Identical numbers: 0 points

➡️Game Over Triggers:-
 The game ends when either all 10 rounds are completed, or if the player's score drops to 0 or below.
